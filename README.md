# 📚 Algoritmos e Técnicas de Programação 1

Repositório dedicado aos exercícios, atividades e projetos desenvolvidos durante a disciplina de **Algoritmos e Técnicas de Programação 1**.

Praticar lógica de programação, desenvolver o raciocínio computacional e aprender os fundamentos necessários para a construção de algoritmos e programas.

- Lógica de programação
- Algoritmos e resolução de problemas
- Variáveis e tipos de dados
- Estruturas condicionais
- Estruturas de repetição
- Funções e modularização
- Exercícios práticos de programação

## 🛠️ Tecnologias

- Linguagem C
- Visual Studio Code
- Git e GitHub

## 📂 Organização

O repositório reúne códigos e atividades desenvolvidos ao longo da disciplina, organizados conforme os exercícios e projetos realizados.
